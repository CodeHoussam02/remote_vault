###### Question 1 : Show each employee’s full name as LAST NAME, First name, with the last name in uppercase and the first name in Title case.

```sql 
SELECT 
CONCAT(UPPER(last_name), ' ', INITCAP(first_name)) EXEMPLE_1, -- This 
UPPER(last_name) || ' ' || INITCAP(first_name) EXEMPLE_2  -- Or this
FROM employees;
```

###### Question 2 : Clean first_name by removing the extra spaces (TRIM) :

```sql 
SELECT 
TRIM(first_name), 
LENGTH(TRIM(first_name)) NAME_LENGTH
FROM employees;
```

###### Question 3 : Lowercase every email and extract the domain ( @gmail.com, @mail.fr ... ) using "SPLIT_PART", "SUBSTRING"

SPLIT_PART(value, delimiter, position_of_extraction)
SUBSTRING(value, Start, Length)
POSITION(substring in string)

```sql 
SELECT 
SPLIT_PART(LOWER(email), '@', 2) DOMAINS
FROM employees;
-- USING SUBSTRING 
SELECT 
LOWER(SUBSTRING(email, POSITION('@' in email)+1, LENGTH(email))) DOMAIN_
FROM employees;
```

###### Question 4 : Show the length of each last name, then keep only the names longer than 5 characters.

```sql 
SELECT 
last_name VALID_NAMES
FROM employees
WHERE LENGTH(last_name)  > 5;
```

###### Question 5 : Normalize the phones: strip spaces, dots and dashes so you get 0612345678 (REPLACE or REGEXP_REPLACE)

REGEXP_REPLACE(source, pattern, replacement_string, flag)
pattern : 
	`[[:digit:]] -- Exclude digits`
	`[[:alpha:]] -- Exclude alphabet`
	`[[:punct:]] -- Exclude punct`
	`[[:space:]] -- Exclude spaces`
	In order to combine alot we write `[[:punct:][:space:]]`
flags : 
	'g' : remouve all alphabet / numerics not only one
	
```sql 
SELECT 
TRIM(REPLACE(REPLACE(REPLACE(phone, '-', ''), ' ', ''),'.', '')) VALID_PHONES
FROM employees;

-- regexp_replace 
SELECT
TRIM(REGEXP_REPLACE(phone, '[[:punct:][:space:]]', '', 'g')) 
FROM employees;
```

###### Question 6 : Build the initials (e.g. A.B.) with LEFT

```sql 
SELECT 
	SUBSTRING(TRIM(UPPER(first_name)), 1, 1) || '.' || SUBSTRING(TRIM(UPPER(last_name)), 1, 1) || '.' INITIALS_
FROM employees;
```

###### Question 7 : Mask the phone so it reads (REPEAT)

```sql 
SELECT 
SUBSTRING(TRIM(REGEXP_REPLACE(phone, '[[:punct:][:space:]]', '', 'g')), 1, 2)
|| REPEAT('*', 6) || SUBSTRING(TRIM(REGEXP_REPLACE(phone, '[[:punct:][:space:]]', '', 'g')), LENGTH(TRIM(REGEXP_REPLACE(phone, '[[:punct:][:space:]]', '', 'g')))-1, LENGTH(TRIM(REGEXP_REPLACE(phone, '[[:punct:][:space:]]', '', 'g')))) PHONE_HIDED
```

### 02. Why to use numpy ?

- regular python lists includes object types or ( object instances ) for each value which consumes a huge amount of memory in order to deal with it.
- numpy array is based on reference point which means numpy arrays carries only data and doesn't care about the methods/props associated to each object in the array
- in general np.arrays are humongously fast than regular python lists
- also numpy arrays uses c in the backend when compiling

#### C'est quoi next-js ?

- next-js et un framework javascript base sur react qui permet de cree des application web d'une maniere simple parcequ'il proposent plusieur features comme : 
			- SSR ( Server Side Rendering )
			- SSG ( Static Site Generation )
			- API routes
			- Des techniques d'authentification modern

#### Les features cle de Next : 

- Server Side Rendering ( SSR )
- Static Site Generation ( SSG ) -> Generation des fichiers html lors du build process de l'applicatio.
- API Routes
- Incremental Static Regeneration ( ISR )
- Dynamic Routing
- Built-in Css and Sass support
- Optimisation des images 
- Automatic Code splitting
- API Middleware 
- TypeScript support
